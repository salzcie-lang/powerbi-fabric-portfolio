For a VP of Sales and regional managers. Four pages: Overview, Products & Margin, Customers & Reps, Order Detail.

## 05 · Data Engineering on Microsoft Fabric

![City Operations Data Platform architecture](05_Data-Engineering/exports/02%20Architecture.png)

A medallion data platform that loads NYC 311 service requests and Open-Meteo weather from public REST APIs into a Gold star schema every day.

- Config-driven PySpark ingestion with high-watermark incremental loads, paging, retry and back-off
- Landing, Bronze and Silver in a lakehouse (Delta); 10 data-quality rules with logged results and a quarantine table
- Gold star schema in a Fabric Warehouse, loaded by T-SQL stored procedures inside transactions
- Row counts reconciled between API, Bronze, Silver and Gold on every run; a mismatch fails the run
- One parameterised pipeline with a failure branch; every run leaves audit rows
- 3.01M requests in Gold; a full daily run takes about six and a half minutes ([run evidence](05_Data-Engineering#run-evidence))

[Details](05_Data-Engineering)

## 06 · Power Automate

![Power Automate architecture](PDFs/Upwork%20Images/Power%20Automate%20-%20Page-1.png)

For a data team that receives business files by folder drop and by email. Four cloud flows, standard connectors only.

- A router copies each dropped file to the landing folder its name says it belongs in, quarantines unknown names and skips oversized extracts
- An alert tells the team what arrived and which refresh to run; a capture flow saves emailed exports; an outbox flow sends a pipeline's digest without the pipeline holding mail credentials
- Deployed and run live: 32 runs, none failed. Routing rules are mirrored by a test

## How the dashboards are built

Each dashboard is a Power BI Project (PBIP), generated and edited as code rather than by hand in Desktop:

1. `_scripts/generate_*.py` creates the seeded synthetic CSV data in each project's `data/` folder.
2. `_scripts/model_*.py` writes the semantic model as TMDL (tables, relationships, measures) through `pbi_model.py`.
3. `_scripts/make_background*.py` draws each page's layout (panels, shadows, gradients, icons) as a background image; visuals sit transparently on top.
4. `_scripts/build_*.sh` places and formats the visuals using the pbir command-line tool.

## Open a dashboard locally

1. Clone the repository and open the `.pbip` file in a project folder with Power BI Desktop (PBIP support enabled).
2. In **Transform data > Edit parameters**, set `DataFolder` to the absolute path of that project's `data/` folder. It defaults to `D:\Portfolio\<project>\data`.
3. Refresh.

The Finance report needs the [Deneb](https://deneb-viz.github.io/) visual, and the Real Estate map needs Azure Maps visuals enabled in your tenant.
