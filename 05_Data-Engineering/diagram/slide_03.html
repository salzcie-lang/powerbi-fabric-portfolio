One pipeline runs the whole load, every day

Ingestion, transformation, the warehouse load and the checks run as a single scheduled job, with one place to look when something goes wrong.
CITY OPERATIONS DATA PLATFORM  ·  03 / 09

01Each step waits for the one before

Each step starts only when the step before it has succeeded. The two API ingests run in parallel; the warehouse loads run in sequence to avoid write conflicts.

02A failure is logged and fails the run

Any failed step triggers a branch that records the failure and marks the run as failed. An email or Teams alert plugs in at that point.

03One parameter, two modes

load_mode switches the same pipeline between the daily incremental load and a full historical backfill.
