Data quality · Bronze to Silver

Every bad row is counted and kept

Real public data is messy. The backfill contained requests closed before they were opened, and thousands with no borough. Each problem is handled by a named rule.
CITY OPERATIONS DATA PLATFORM  ·  06 / 09

01Rules run on every load

Ten rules check keys, dates, locations and duplicates each time data moves from Bronze to Silver.

02Rejected rows go to quarantine

Rows that cannot be trusted go to a quarantine table with the reason. Rows with one bad field are repaired and flagged, so analysts can include or exclude them.

03Rule results are stored

Every rule writes how many rows it checked and how many failed to meta.dq_results, so quality can be trended and alerted on like any other metric.
