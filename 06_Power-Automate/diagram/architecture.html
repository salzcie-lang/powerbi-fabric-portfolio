3 · Destinations

Where they end up

SharePoint landing zone

Quotes · Contracts · Design Registrations · Price List · Inventory · Trend Exports

One folder per file family, read by dataflows and a Fabric pipeline. Quarantine and outbox folders sit beside them.

Data team inbox

One email per arrival with the refresh step to run. Refreshes are not triggered automatically, because source layouts change.

Dataflows and Power BI

Downstream readers that expect exact names. The flows match their case rules, so a file never sits unread.

4flows · 3 connectors · every run logged
Filter at the trigger

Noise never starts a run

Lock files, folders, wrong extensions and unrelated emails are rejected by trigger conditions, so run quota and run history stay clean.

Match the reader

Case policy per file family

Most rules are case-insensitive. Inventory names are case-exact because the dataflow that reads them is. Rule order handles names that contain other names.

Fail visibly

Quarantine plus an alert

A file that matches no rule is copied to _Inbox Unrouted and emailed at high importance, instead of landing where nothing reads it.

Hand-off contract

The folder is the status

The pipeline holds no mail credentials and never calls a Premium endpoint. Pending → Sent / Rejected tells it what happened.
